# Купонная книжка

Личный трекер инвестиций: купоны, дивиденды, пассивный доход до и после налога, доход по месяцам, активы с ценами Мосбиржи, история операций, прогноз и аналитика. Сайт лежит на GitHub Pages, данные хранятся в Supabase.

## Что внутри

```
index.html                    страница сайта
css/app.css                   оформление
js/config.js                  ← сюда вписать адрес и ключ Supabase
js/*.js                       логика: расчёты, Мосбиржа, импорт, графики
vendor/pdfjs/                 программа для чтения PDF-отчётов (Mozilla pdf.js)
supabase/schema.sql           таблицы для Supabase
supabase/functions/moex-proxy запасной канал к Мосбирже (нужен не всегда)
```

## Запуск: 5 шагов

### 1. Таблицы в Supabase

Можно в том же проекте, что и платформа: все таблицы трекера начинаются с `inv_` и ни с чем не пересекаются.

1. Supabase → **SQL Editor** → New query.
2. Вставьте весь файл `supabase/schema.sql` и нажмите **Run**. Скрипт можно запускать повторно, он ничего не сломает.

Каждый пользователь видит только свои операции. Это обеспечивают правила доступа (RLS), без входа данные недоступны.

### 2. Вход

Если таблицы в проекте платформы, можно входить той же почтой и паролем, что и на платформе.

Если нужен отдельный вход: **Authentication → Users → Add user → Create new user**, укажите почту и пароль и отметьте **Auto Confirm User**.

Ученики платформы тоже смогут войти на этот сайт, но увидят только пустую книжку: чужие данные им недоступны. Если хотите, чтобы сайтом пользовались только вы, создайте для него отдельный проект Supabase.

### 3. Ключ в config.js

Supabase → **Project Settings → API**. Скопируйте **Project URL** и ключ **anon public** (те же, что в коде платформы) и впишите в `js/config.js`:

```js
supabaseUrl: 'https://xxxxxxxx.supabase.co',
supabaseAnonKey: 'eyJ...',
```

Этот ключ публичный по задумке Supabase, его можно хранить в репозитории: данные защищены входом и правилами доступа.

### 4. GitHub Pages

1. Создайте на GitHub новый репозиторий, например `kupon`.
2. **Add file → Upload files**, перетащите всё содержимое папки (вместе с папками `css`, `js`, `vendor`, `supabase`) → Commit.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
4. Через минуту-две сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/kupon/`.

Бесплатный GitHub Pages работает только с публичным репозиторием. Это нормально: в репозитории лежит только код, а ваши операции хранятся в Supabase.

### 5. Мосбиржа (только если не грузятся цены)

Сайт берёт цены, купоны и графики амортизации прямо с Мосбиржи. Если вверху справа горит красное «Мосбиржа · нет связи», подключите запасной канал через Supabase:

1. Supabase → **Edge Functions → Deploy a new function → Via Editor**.
2. Имя функции: `moex-proxy`. Вставьте код из `supabase/functions/moex-proxy/index.ts`.
3. Выключите **Verify JWT** (функция открытая, но пропускает только запросы к открытым данным биржи) → **Deploy**.
4. В `js/config.js` впишите `moexProxyUrl: 'https://xxxxxxxx.supabase.co/functions/v1/moex-proxy'` и загрузите файл на GitHub заново.

## Первый раз: перенос из Т-Банка

1. В Т-Инвестициях закажите **брокерский отчёт в PDF** за каждый месяц с открытия счёта, по обоим счетам.
2. На сайте: **Операции → Загрузить отчёты** → выберите сразу все файлы.
3. Сайт разложит отчёты по договорам. Для каждого договора выберите счёт («Облигации» или «Акции»), сайт это запомнит.
4. Проверьте три отметки:
   - **остаток денег сходится** — все строки отчёта прочитаны;
   - **количество бумаг совпадает** с остатками на конец последнего месяца, значит, ни одна покупка не потерялась;
   - **не хватает отчётов за …** — каких месяцев недостаёт.
5. Нажмите **Добавить**.

Повторная загрузка безопасна: что уже есть, второй раз не добавится.

## Каждый день и каждый месяц

- Новые покупки вносите вручную: **+ Операция**. Цену облигации можно указать в процентах, как в стакане, комиссию — в процентах, например `0,3%`.
- В начале месяца загрузите отчёт за прошлый месяц. Ручные записи, которые совпали с отчётом, заменятся записями из отчёта, дубликатов не будет.
- Какие месяцы уже загружены, видно в разделе **Операции → Загруженные отчёты**.

## Налог

В настройках (шестерёнка): купоны 30%, дивиденды 15% (ставки для нерезидента РФ). Если станете налоговым резидентом РФ, поставьте 13%: все суммы «после налога» пересчитаются. Если в отчёте видно удержанный налог, сайт берёт его, а не ставку.

## Резервная копия

- **Операции → Экспорт CSV** — все операции в одном файле. Этот же файл можно загрузить обратно через «Загрузить отчёты».
- Если в Supabase настроен ночной бэкап через GitHub Actions, таблицы `inv_` попадают в него сами.
